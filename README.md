# pr3,3_Novikov

Учебный Android-проект для практической работы по Git.

## О проекте

Приложение создано в Android Studio на Kotlin с использованием Jetpack Compose. Стартовый экран показывает приветствие.

## Сборка

Откройте проект в Android Studio и запустите Gradle Sync. Минимальная версия Android: API 29.
